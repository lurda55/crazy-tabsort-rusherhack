# Crazy TabSort

RusherHack plugin by **lurda55**.

TabSort module: friends at the top of the tab list, enemies right under them.

## Install

1. Download `crazy-tabsort-1.0.0.jar` from the [latest release](https://github.com/lurda55/crazy-tabsort-rusherhack/releases/latest).
2. Put it in `.minecraft/rusherhack/plugins/`.
3. Start Minecraft 1.21.11 with RusherHack (plugins must be enabled: `-Drusherhack.enablePlugins=true`).

## Build

```
./gradlew build
```

The jar is in `build/libs/`.
